Registration Form
Overview

A static HTML registration page built as a Week 1 homework assignment. The page contains a "Create your account" form written in plain HTML, with no styling frameworks or JavaScript logic.

Assignment

The task was to recreate a provided registration form design using HTML only. The form had to include:

Full name, email, password, and phone fields
A birth date field
A country dropdown list
A preferred contact option (Email or Phone)
A checkbox to accept the terms
A submit button

The goal of the assignment was to practice building forms with the correct input types, labels, and grouping elements.
